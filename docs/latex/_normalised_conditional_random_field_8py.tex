\doxysubsection{Detailed Description}
Optic disc and cup segmentation using Naive Bayes classifier with Dense CRF refinement and normalized features. 

This module implements a memory-\/efficient pipeline for retinal image segmentation that combines Gaussian Naive Bayes classification with normalized color features and Dense Conditional Random Field (CRF) post-\/processing to segment optic disc, cup, and background regions from fundus images. Includes comprehensive metrics comparison with mean and standard deviation reporting.

Memory-\/efficient main execution pipeline with normalized features and CRF refinement. 

Executes the complete segmentation workflow including\+:
\begin{DoxyItemize}
\item Configuration of data directories and processing parameters
\item Loading and preprocessing training data with memory-\/efficient batching
\item Training Gaussian Naive Bayes classifier with normalized color features
\item Testing on validation images with ground truth evaluation
